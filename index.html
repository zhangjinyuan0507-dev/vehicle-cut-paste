🧩 光谱与类别组（各套分开）

光谱：红外（灰度素材）／可见光（彩色素材，两套配色）——建议各自用不同的输出目录
类别组：基础四类 car1 装甲车 / car2 卡车 / car3 轿车 / car4 皮卡；类增量新四类 radar_vehicle 雷达车 / military_fuel_tanker 军用油罐车 / bridge_layer 轮式架桥车 / military_motorcycle 军用越野摩托车
类别 ID 为官方口径：旧类 0~3 不变，新类从 4 起追加。同一建模的两套配色、两套光谱共享 family，划分数据集时不要拆开。
同一张图里混了不同光谱/类别组的数据会在「标注计划」里给出警告。
